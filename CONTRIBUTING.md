# Contributing

This is an early personal project. Keep runtime data, user documents, chat history, model weights, secrets, and local databases out of Git.

Before submitting changes:

- run `bash -n install.sh start.command stop.command scripts/*.sh`;
- update the README if setup or behavior changes;
- test on macOS, ideally on the target 8 GB MacBook Neo;
- be explicit about which features are implemented versus planned.
